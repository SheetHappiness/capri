# Capri v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a single-owner Python Telegram agent through npm, using OMP and Codex subscription access, with responsive streaming, useful actions and durable local state.

**Architecture:** Python owns application policy and presentation; a thin adapter hosts the official OMP RPC client. aiogram handles Telegram; SQLite stores Capri state while OMP keeps its own sessions. A Node launcher prepares app-local runtimes.

**Tech Stack:** Python 3.14, aiogram 3.31.0, official omp-rpc wheel built from pinned upstream source, OMP binary candidate 18.12.6, uv candidate 0.13.5, Node 24+, SQLite, pytest/pytest-asyncio, Node built-in test runner.

**Spec:** [Capri design](../specs/2026-10-24-capri-design.md). [Research and evidence](../specs/2026-10-24-capri-research.md).

**Status:** Proposed; no implementation, installation, auth or live tests authorized by this planning session. User approves design and plan together before execution. Dates below describe a target schedule, not an execution already performed.

## Global Constraints

- Windows x64 — перший release target.
- Node 24+ і npm уже встановлені, є мережа; OMP, Bun, Python та uv не потрібні користувачу заздалегідь.
- Guest дозволений лише verified owner caller; unknown/anonymous caller fail closed.
- Guest має web only; без host side effects.
- `gpt-6-luna` is the requested primary model; no silent replacement.
- Не переписувати OMP для жодного варіанта.
- Нема desktop pet, Discord, vector DB, другого agent loop, browser engine, general plugin framework, multiuser service, OS service installer чи складного multi-agent orchestrator.
- Voice/TTS — v0.2, з reserved capability без fake tool.
- Заборонено використовувати GPT-6 Astra для subagents.
- No commit/push/npm publish or third-party communication without user authorization. Task review artifacts stay local until requested otherwise.

## Review Focus

1. Accepted non-idempotent Telegram send times out: mark uncertain and suppress automatic resend (Task 4).
2. OMP callback arrives after interrupt or maps to the wrong prompt: reject stale epoch and preserve public text order (Tasks 2, 5).
3. Guest chat ID collides with a real owner chat ID: query-only routing and no shared context (Task 7).
4. Bootstrap is interrupted, scripts disabled, or install path contains spaces/Unicode: retry safely using absolute executable paths (Tasks 1, 10).
5. Sleep/restart/DST crosses a reminder or inactivity window: durable one-shot jobs and bounded heartbeat without notification storm (Task 8).
